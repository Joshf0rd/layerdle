# Song ideas by category

Each line is already a filename: copy it, add `.mp3`, and put the file in `incoming\<Category>\`.
The same song can go in several category folders.
Windows doesn't allow `\ / : * ? " < > |` in filenames, so those are left out (e.g. ACDC, Snowman).
