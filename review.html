How to fix a bad clip
  1. Listen to the full song and note where the clip should start, e.g. 1:05.
  2. Tap Fix this clip on the song, type the time, and copy the file name it makes.
  3. On the PC, find the song's MP3 in incoming\done, rename it to that name and move it into incoming.
  4. Double-click add_songs.cmd. It re-makes that song's clips and publishes them.
